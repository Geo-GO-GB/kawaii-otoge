# The KAWAII☆音ゲー
5キーのポップな音ゲー（ポップン／ビーマニ風）＋ オリジナル曲18曲

公開ページ：https://geo-go-gb.github.io/kawaii-otoge/

## あそびかた
1. ブラウザ（Chrome / Edge 推奨。Firefoxも可）で [公開ページ](https://geo-go-gb.github.io/kawaii-otoge/) をひらく。音・画像・フォントはページから読み込みます（ネット接続が必要です）。
2. 最初の「♪ CLICK TO START ♪」でクリックかキー（ブラウザの決まりで、ユーザー操作のあとでないと音が出せないためのゲートです）。
3. **タイトル**（タイトルBGMがループ）。メニューは回転式で、**START**（ゲーム）／ **JUKEBOX**（曲と歌詞を聴く）／ **CREDIT** ／ **遅延調整** ／ **設定** の5つ。↑↓やクリックで選んで Enter。
4. **キャラクター選択**：←→で18キャラからえらんで Enter。選んだキャラはgoodポーズで反応します。
   ライバルはその曲のキャラで固定（その曲のボーカル／担当キャラと同じ。同じキャラを選ぶと右側は2Pカラー（青）のミラー対決になります。アコ（フェスver）を選んだときだけ例外）。ライバルのモーションはプレイヤーの判定の逆です（good→miss、miss→good、fever中はライバルがmiss）。
5. **曲選択**：↑↓で18曲を切りかえ（端まで行くとループ）。選んだ曲のサビ／テーマがフェードイン→フェードアウトでくり返し試聴されます。タイトル・ジャンル・BPMと **EASY / NORMAL / HARD**（←→で切りかえ、**Lvとノーツ数つき**）を表示。Enter か **START!** で開始。
6. 上から落ちてくるノーツが判定ラインのマーカーに重なったらキーをたたく！

| レーン | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| キー（標準） | **Q** | **W** | **E** | **R** | **T** |
| キー（切りかえ） | **D** | **F** | **SPACE** | **J** | **K** |
| ノーツの色・マーク | 白 ● | イエロー ◆ | ピンク ★ | シアン ♥ | オレンジ ▲ |

設定（タイトル画面と曲選択画面の両方から開けます）：キー配置・ポップン レーン・ノーツの見た目（ふつう／スリム）・キーコンフィグ（ゲームパッド用）・ハイスピード・タイミング調整・BGM／キー音の音量・オートプレイ・キー音のみ。設定はブラウザに保存されます。

- 判定：PERFECT ±42ms / GREAT ±85ms / GOOD ±130ms / それより遅れるとMISS
- クリア条件：曲の終わりにゲージが 70% 以上（CLEAR ラインより右）
- Esc：プレイ・リザルト→曲選択 / 曲選択→キャラ選択 / キャラ選択・クレジット→タイトル。リザルトで Enter：もういちど
- **タイミング調整**：SLOWが多いと感じたら＋、FASTが多いなら−へ。タイトル画面の **遅延調整** では、メトロノームに合わせてタップする方式の調整もできます
- 画面のレーンをクリック／タップしても叩けます

### ゲームパッド対応
- **ポップンミュージック コンパクトコントローラ**（KONAMI公式）に対応。9ボタンをそのまま使います（メニューは青＝選択移動・黄＝サブ選択・赤＝決定、白＝設定）。プレイ中のレーン割り当ては「外側（白・緑・赤・緑・白）」と「中央（緑・青・赤・青・緑）」の2セットから設定で切りかえられます。SELECTボタンはプレイ中に即・曲選択へ戻ります。
- **標準ゲームパッド**（Switch Proコントローラ／Xbox／PlayStation系）にも対応。プレイ中は十字キーとボタンで5レーンを叩きます。設定の **キーコンフィグ** で、プレイ中のボタン割り当てだけを自由に変えられます（メニュー操作は画面ごとに固定です）。
- 接続中のパッドがあるときは、画面左下に 🎮 マークが出ます（キーボードで操作すると自動でキーボード表示に戻ります）。

### キー音（ビーマニ方式）
ノーツ1つ1つが「曲の本物の音」を持っています。たたくとその音が鳴り、**ミスするとその音が抜けます**。伴奏としてずっと流れるパートもあります。
EASY / NORMALで譜面に入っていない音は自動で鳴るので、曲はちゃんとつながります。歌のある曲では右パネルに歌詞カードが出て、歌われた文字からピンク色に変わっていきます（間奏は ♪ 表示）。「O Numen Altissimum」では日本語訳が小さく併記されます。JUKEBOXでも歌詞が表示されます。

### 画面まわり
- ポップでカラフルな配色（イエロー・ピンク・シアン・オレンジ・ライム＋ネイビーのフチと白）。ななめパネル、網点、切り抜き文字風ロゴ。FEVER中は背景が虹色に変化。デザインはオリジナルで、既存ゲームの素材やロゴは使っていません。
- **ノーツ**はコードで描いたカプセル型：太い白フチ＋レーン色の塗り＋ネイビー（#1E1B3A）のマーク（● ◆ ★ ♥ ▲）。判定ラインのマーカーとレーン下のキーボタンも同じ色・マーク。設定で **スリム**（細いノーツ＋同時押しをつなぐライン表示）にも切りかえられます。
- 判定（PERFECT／GREAT／GOOD／MISS）は叩いたレーンの上にポップアップ表示。コンボ数はレーン中央に大きく半透明で表示されます。
- カットインは左右のキャラパネルの中だけに出ます（レーンには絶対にかぶりません）。キャラ名のネームプレートつき。
- 音：タイトルBGM、キャラ選択BGM、曲選択の試聴（曲ごとに切りかわる）、「イエーイ!!」シャウト、メニュー効果音。

### キャラの動き（ポップン方式・ハンドトゥーン）
左＝プレイヤーキャラ、右＝ライバル。どちらもスプライトシートで動きます：
- idle（ふだん）＝ループ / good（GREAT・PERFECTが5連続ごと）・miss（MISS）＝1回再生してidleの先頭にもどる / fever（30コンボ以上）＝ループ
- リザルト：クリアならプレイヤーwin・ライバルlose、失敗なら逆。win/lose は最後まで再生したあと途中のフレーム（loop_start）からゆらゆらループ。
- idle↔fever、win/lose への切りかわりは数フレームのクロスフェード。
- 25・50・100・150・200・250コンボと FEVER突入でカットイン。
