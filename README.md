# The KAWAII☆音ゲー
5キーのポップな音ゲー（ポップン／ビーマニ風）＋ オリジナル曲3曲

## あそびかた
1. `game.html` をデスクトップのブラウザ（Chrome / Edge 推奨。Firefoxも可）でひらく。ネット接続は不要です（音・画像・フォントぜんぶ入り）。
2. 最初の「♪ CLICK TO START ♪」でクリックかキー（ブラウザの決まりで、ユーザー操作のあとでないと音が出せないためのゲートです）。
3. **タイトル**（タイトルBGMがループ）→ なにかキーで「**イエーイ!!**」のシャウト → **キャラクター選択**（専用BGM）。右下の **CREDIT** でクレジット画面。
4. **キャラクター選択**：←→で **ケッティ**（ケット・シー）・**デビボ**（ロボ悪魔）・**ニコチン**（ヘビースモーカー）をえらんで Enter。選んだキャラはgoodポーズで反応します。
   ライバルはその曲のキャラで固定（ケッティ曲＝ケッティ、デビボ曲＝デビボ、ニコチン曲＝ニコチン）。同じキャラを選ぶと右側は2Pカラー（青）のミラー対決になります。ライバルのモーションはプレイヤーの判定の逆です（good→miss、miss→good、fever中はライバルがmiss）。
5. **曲選択**：↑↓で3曲を切りかえ（端まで行くとループ）。選んだ曲のサビ／テーマがフェードイン→フェードアウトでくり返し試聴されます。タイトル・ジャンル・BPMと **EASY / NORMAL / HARD**（←→で切りかえ、**Lvとノーツ数つき**）を表示。
   オプション：キー配置（標準：Q W E R T ／ 切りかえ：D F SPACE J K）・ハイスピード・タイミング調整・音量・オートプレイ。Enter か **START!** で開始。
6. 上から落ちてくるノーツが判定ラインのマーカーに重なったらキーをたたく！

| レーン | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| キー（標準） | **Q** | **W** | **E** | **R** | **T** |
| キー（切りかえ） | **D** | **F** | **SPACE** | **J** | **K** |
| ノーツの色・マーク | 白 ● | イエロー ◆ | ピンク ★ | シアン ♥ | オレンジ ▲ |

設定（キー配置・むずかしさ・ハイスピード・タイミング・音量）はブラウザに保存されます。

- 判定：PERFECT ±42ms / GREAT ±85ms / GOOD ±130ms / それより遅れるとMISS
- クリア条件：曲の終わりにゲージが 70% 以上（CLEAR ラインより右）
- Esc：プレイ・リザルト→曲選択 / 曲選択→キャラ選択 / キャラ選択・クレジット→タイトル。リザルトで Enter：もういちど
- **タイミング調整**：SLOWが多いと感じたら＋、FASTが多いなら−へ。
- 画面のレーンをクリック／タップしても叩けます

### キー音（ビーマニ方式）
ノーツ1つ1つが「曲の本物の音」を持っています。たたくとその音が鳴り、**ミスするとその音（歌のある曲では歌詞の1文字）が抜けます**。ドラム・ベース・コードは伴奏としてずっと流れます。
EASY / NORMALで譜面に入っていない音は自動で鳴るので、曲はちゃんとつながります。右パネルの歌詞は、ミスした文字がグレーになります（`hasVocal` が false の曲では歌詞パネル自体を出しません）。

ケッティ曲の歌は子音が拍より前に出るので、キー音は **t − pre** で鳴します。ニコチン曲のリードは拍より約15ms遅れて鳴ります（`pre` が負）。キー音の音量は曲ごとの `keys_gain`（ケッティ 1.43、ニコチン / デビボ 1.0）を伴奏に対してかけています。

### 譜面とレベル（Lvは暫定。遊んでから調整する）
| 曲 | EASY | NORMAL | HARD |
|---|---|---|---|
| ニャンニャン☆マジカル・スターライト!!（ケッティ、BPM170） | Lv8（156ノーツ） | Lv18（284） | Lv41（533） |
| デビボ☆フィーバー・ナイト!!（デビボ、BPM156） | Lv9（88） | Lv14（168） | Lv35（282） |
| けむりの輪っか（スモーク・リング）（ニコチン、BPM96 スウィング） | Lv6（84） | Lv12（186） | Lv19（281） |

画面では「Lv 14*」のように * つき。式はデビボ曲と同じものに、同時押しのある譜面では同時押しの項を足したものです。実際に遊んだ感覚で調整していない機械的な目安です。

### 画面まわり
- ポップでカラフルな配色（イエロー・ピンク・シアン・オレンジ・ライム＋ネイビーのフチと白）。ななめパネル、網点、切り抜き文字風ロゴ。FEVER中は背景が虹色に変化。デザインはオリジナルで、既存ゲームの素材やロゴは使っていません。
- **ノーツ**はコードで描いたカプセル型：太い白フチ＋レーン色の塗り＋ネイビー（#1E1B3A）のマーク（● ◆ ★ ♥ ▲）。判定ラインのマーカーとレーン下のキーボタンも同じ色・マーク。
- コンボ数と判定はレーン中央に大きく半透明で表示（ノーツより下に描くので、ノーツはいつでも見えます）。
- カットインは左右のキャラパネルの中だけに出ます（レーンには絶対にかぶりません）。キャラ名のネームプレートつき。
- 音：タイトルBGM、キャラ選択BGM、曲選択の試聴（曲ごとに切りかわる）、「イエーイ!!」シャウト、メニュー効果音。

### キャラの動き（ポップン方式・ハンドトゥーン）
左＝プレイヤーキャラ、右＝ライバル。どちらもスプライトシートで動きます：
- idle（ふだん）＝ループ / good（GREAT・PERFECTが5連続ごと）・miss（MISS）＝1回再生してidleの先頭にもどる / fever（30コンボ以上）＝ループ
- リザルト：クリアならプレイヤーwin・ライバルlose、失敗なら逆。win/lose は最後まで再生したあと途中のフレーム（loop_start）からゆらゆらループ。
- idle↔fever、win/lose への切りかわりは数フレームのクロスフェード。
- 25・50・100・150・200・250コンボと FEVER突入でカットイン。

## ファイル
- `game.html` … ゲーム本体（音・画像をbase64で埋め込み、単体で動く）

- `build/songs/ketty/`・`build/songs/nicotine/` … 新曲の伴奏・キー音・譜面・song.json
- `incoming/*_fixed/` … 手描きアニメの修正済みフレーム（原本は `incoming/*_anim/`）
- `licenses/` … フォント（Dela Gothic One / Anton / M PLUS Rounded 1c、いずれも SIL OFL 1.1）と HTS Voice Mei（CC BY 3.0）のライセンス全文
- `docs/charts_new_songs.md`・`docs/song_ketty_plan.md`・`docs/song_nicotine_plan.md` … 譜面と曲の企画

## 注意・制限
- フォントはこのゲームで使う文字だけを埋め込んでいるので、文章を書き足すときは `build_game.py` を再実行してください。
- デビボのボーカルはロボ声です。1文字ずつ合成して音程をメロディに固定しているので、歌詞が聞き取りにくい所があります。
- 音はプログラム合成が中心なので、市販曲ほど厚くはありません。
- ブラウザやPCで音の遅れがちがうので、ズレを感じたらタイミング調整を使ってください。
- Dela Gothic One の書体では「ケ」が「ク」に少し似て見えます。
- Safariは OGG Vorbis が再生できないことがあります（Chrome / Edge / Firefox 推奨）。
- `game.html` は3曲分の音を埋め込んでいるためファイルサイズが大きくなります。
